## Run a Solution

Open a terminal in the repository and compile an individual source file:

```powershell
g++ "week 1\Day 1\day1.cpp" -std=c++17 -o "day1.exe"
.\day1.exe
```

Use the same pattern for any solution:

```powershell
g++ "path\to\solution.cpp" -std=c++17 -o "solution.exe"
.\solution.exe
```
