# Daily Problem Solving

A collection of C++ solutions written as part of a daily problem-solving practice routine.

The repository includes solutions to algorithm and data structure problems from:

- LeetCode
- VJudge programming contests

## Repository Structure

```text
week 1/
  Day 1/
  Day 2/
  ...
week 2/
  Day 1/
  ...
week 3/
  Day 1/
  ...
```

Each day is usually organized into:

- `solution.cpp` or another C++ solution file
- `the problem` or `problem`, containing the original problem statement when available

## Language

- C++17 or later
- MinGW/GCC on Windows

## Running a Solution

Open a terminal in the repository, then compile and run an individual source file:

```powershell
g++ "week 1\Day 1\day1.cpp" -std=c++17 -o "day1.exe"
.\day1.exe
```

Replace the source path with the solution you want to run.

VS Code C/C++ configuration and build tasks are included for development on Windows.
